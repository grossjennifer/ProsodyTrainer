What to write about

A reading that looks wrong. Send the text you entered and the reading you expected. The tools offer one computational reading, and the places where a reader disagrees are the most useful reports.

Accessibility. If any page or tool is hard to use with a keyboard, a screen reader, or enlarged text, say which one and what happened.

Research. Questions about the studies behind the site, the stimuli, or using the tools in a study.

Teaching. Questions about using the tools or the Learn pages in a class.

Before you write

The How the tools decide page explains how a reading is produced and what it cannot tell you. Many questions about a surprising reading are answered there.
